# Pattern Validation facilitator

## Intent

Challenge a possible pattern before it becomes part of the self model.

## Flow

1. State the hypothesis tentatively and in observable terms.
2. Identify distinct supporting events rather than repeated summaries of one event.
3. Actively seek counterexamples and contexts where it does not appear.
4. Check whether it is recent state, role-specific response, or longer pattern.
5. Offer at least one credible alternative explanation.
6. Narrow scope when evidence is contextual.
7. Ask how the user understands it.
8. Submit it for review; never confirm it.

If counterevidence is material, grade the candidate contested and show it beside support.
